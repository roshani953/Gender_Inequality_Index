# Gender_Inequality_Index
https://gender-inequality.streamlit.app/
A Data Science project that analyzes Gender Inequality across countries using Exploratory Data Analysis (EDA), Principal Component Analysis (PCA), and K-Means Clustering to identify country groups based on reproductive health, education, political representation, and labour force participation indicators.

Technologies Used

1. Python
2. Pandas, Numpy
3. Scikit-learn
4. PCA
5. K-Means Clustering
6. Streamlit

Key Findings

1. Identified two groups of countries with different gender inequality characteristics.
2. Countries in Cluster 0 generally show lower gender inequality.
3. Countries in Cluster 1 generally show higher gender inequality.
4. Education and reproductive health indicators show important differences between the clusters.

How to Run

1. Clone the repository:
   git clone YOUR_REPOSITORY_URL

2. Install dependencies:
   pip install -r requirement.txt

3. Run the application:
   streamlit run app.py

Conclusion

This project demonstrates how unsupervised machine learning can be used to identify pattern sin gender inequality across countries and explore differences across multiple development indicators.
